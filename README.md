# XFile-Explorer

​🚀 XFile Explorer
​XFile Explorer is a feature-packed, super-customizable file manager app and power tool built for Android! It combines clean, fast file browsing, a full media suite, app management, and a built-in terminal loaded with 182 commands to give you total control over your device.

​No ads 🚫
no subscriptions 💳, 
zero background tracking 🕵️‍♂️
and local control 🔒.

​🔥 Features:

​📁 Fast File Management: Smooth local storage browsing with copy, move, rename, delete, batch operations, and zip handling.

​📊 Smart Storage Reader: Accurately inspect user-accessible storage by filtering out system-reserved space (for example, on a 120 GB device with 20 GB reserved for the OS, it calculates usage out of the remaining 100 GB).

​🎬 Built-in Media Viewer: Preview and play your media directly in the app with built-in support for images, videos, and music.

​📄 Built-in PDF Viewer: Open and read PDF documents instantly right inside the app.

​📱 Built-in App Viewer: Inspect installed apps and launch them directly. It also lists hidden system services so you can easily access their App Info panels in system settings.

​🎨 Deep Customization: Tweak themes, layouts, and colors to make the app look and feel exactly how you want.

​🌡️ Phone Heat Viewer: Real-time phone thermal monitoring estimated directly from your battery sensor data.

​💻 Integrated Terminal: Built-in command terminal equipped with 182 commands for system execution and file management.

​📦 Zip Management: Native ZIP creation and extraction. Adheres strictly to the ZIP Golden Rule—ZIP contents remain private and protected, so files inside cannot be viewed or edited until fully extracted.

​📖 Offline Help Pages: Built-in reference documentation for terminal utilities so you can check commands anytime.

​🛡️ 100% Ad & Subscription Free: Completely free of ads, paywalls, and telemetry.
​Terminal Usage: Managing Permissions & 

Unlocking Advanced Commands 🔓
​If you want to unlock additional commands that require specific system permissions, follow these steps in the terminal:

​💻 Open the terminal and type:

permissions

​This command outputs a list of all granted and ungranted permissions, accompanied by the exact syntax names to simplify command entry.

​🔍 Identify the ungranted permission required for the commands you want to unlock.

​⚡ Grant the permission using the following command:

grant permission «permission_name» 

(when typing this command, please don't include «»)

​Technical Specifications ⚙️:

​📱 Platform: Android

​🛠️ Environment: File Manager, App Manager, Settings, and Built-in terminal with 182 integrated utilities

​💾 App Size: 29 MB

​🔒 Privacy: 100% local storage & offline operation

​🛡️ File Safety Protections: Dots cannot be typed when naming files, and file extensions cannot be manually edited—extensions are selected from a preset list (.py, .txt, .json, .js, .html, .css, .kt, .java, .xml, .sh, .md, .sql). {Note: If you do not like these file safety protections, please use another file manager app.}

​🚫 Android data & obb Directories: Browsing or viewing the /Android/data and /Android/obb directories is not supported. {Note: If you do not like this limitation, please use another file manager app.}

​⚡ Shizuku Support: Not supported
